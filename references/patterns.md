# 版式配方

每种版式给：适用场景、布局数学、要点。默认画布 1600 宽，内容区 48≤x≤1552。

## 1. 分层架构（TTB bands）★最常用

适用：系统总体架构、技术栈、请求链路分层。
- 每区间高 150-230px：层标题行（2 行小号灰字）+ 卡片行
- 卡片等高，等宽均匀分布：w=(1460-(n-1)*20)/n，起始 x=190（左侧留给层编号）
- 左侧 x=58 放 `bandLabel`（01/02…+层名），彩色与层主色一致
- 层间：纵向箭头 x≈800，sw=2.4，带白底标签说明过渡语义
- 底层可放基础设施 pill 行（slateT 底）
- 中心组件可放大（如 Agent Loop 宽 400 高 190），双侧组件水平箭头双向连接

## 2. 多面板组合（columns/panels）

适用：Profile/Bundle 组合、部署形态矩阵、多方案对比。
- 2-5 个白底大面板（rx=20 shadow），面板间可选语义箭头
- 面板内：sectionTitle（16px/700+12px 灰注）+ 行式小卡或堆叠层
- 堆叠层叠关系用自上而下的卡片堆 + "按 X 追加"灰注
- 优先级/顺序用编号圆点列表（1-4，tint 圆 + mono 数字）

## 3. 泳道流水线（swimlane）

适用：工具执行流水线、审批流、CI 流程。
- 4-5 条横向泳道：tint 55% 底 + 左侧 14px/700 彩色道名
- 节点卡片沿主流程 S 形推进，道间用 pathArrow 下行
- 拒绝/异常路径：roseT 虚线框 + rose 虚线箭头，汇聚到统一的失败归一化说明 pill
- 决策点直接画在泳道卡里（如"审批"），不单独画菱形以保持卡片一致性

## 4. 枢纽辐射（hub-spoke）

适用：能力接缝、插件生态、事件总线。
- 中心：ink 深底大圆角矩形（白字）= 运行时/总线
- 三列：定义（左）→ 提供者（中）→ 消费方（右），列间带语义标签的水平箭头
- 底部放一条示例带：pill 链（A→B/C/D→E）说明一个具体接缝
- 节点多时每列用 tint 底卡（非白卡）区分层级

## 5. 同心防御（concentric）

适用：安全纵深、权限分层。
- 3-4 层嵌套圆角矩形（外→内：rose→amber→teal→blue，tint 底+主色描边）
- 每层左上角：①编号+层名（17px/700）+ 12px 说明
- 最内层放 2×2 小卡网格（执行世界选项）
- 右侧放"失败关闭"原则卡列 + 边界卡列；底部放预设 pill 行
- 层间左侧画"逐层收敛"折返箭头

## 6. 网格地图（grid map）

适用：包/模块生态地图、团队分工、能力盘点。
- 顶部统计卡行：6 张等高卡（28px/700 彩色大数字 + 12px 灰标签）
- 主体 2 列 × N 行分组卡：每卡左缘 5px 主色竖条 + 组名 + 灰注
- 组内成员用小 pill（tint 底）：名称 mono 彩色 + 数量右对齐
- 底部放注释行（统计口径说明）

## 7. 事件溯源 / 中心辐射数据流

适用：日志派生、单一事实来源、CQRS。
- 中央深色大卡（ink 底）= 事实源：白 title + mono 彩色事件行列表
- 左侧输入卡列（写入），右侧派生卡列（视图），pathArrow 曲线进出中心
- 底部用一条 blueT 通栏写不变量（①②③…）

## 通用要点

- 画布高度按内容定（900-1160），frame 页脚自动贴底
- 任何文字与卡片边缘 ≥12px；图标徽章与文字基线对齐
- 颜色语义与 design-system.md 一致：安全用 rose、模型/云用 amber、持久化用 violet、工具/执行用 teal、核心引擎用 blue、UI/消费方用 violet/cyan
- 多图成册时：同一色调映射同一语义，跨图不漂移
